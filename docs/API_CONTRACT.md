# API Contract

This document describes the HTTP endpoints exposed by the AI-Assisted Software Engineering Prototype.

Base URL for local development: `http://127.0.0.1:8000`

## 1. POST /api/urls

Creates a short URL and stores the original URL in the SQLite database.

### Request

Content-Type: `application/json`

```json
{
  "url": "https://example.com/products/123"
}
```

### Successful response

Status: `201 Created`

```json
{
  "shortCode": "generated-code",
  "originalUrl": "https://example.com/products/123",
  "shortUrl": "http://127.0.0.1:8000/r/generated-code",
  "createdAtUtc": "2026-10-21T15:47:52.820461+00:00"
}
```

The short code and timestamps are generated by the application. The example values are illustrative.

### Error responses

- `422 Unprocessable Entity`: Request validation fails, such as when the URL is invalid or uses an unsupported scheme.
- `503 Service Unavailable`: The application cannot allocate a unique short code after the configured retry attempts.

## 2. GET /r/{short_code}

Redirects the client to the original URL associated with the supplied short code.

### Successful response

- Status: `302 Found`
- The `Location` response header contains the original URL.
- The click count is incremented, and the last-accessed timestamp is updated.

### Error response

- `404 Not Found`: The short code does not exist.

## 3. GET /api/urls/{short_code}/analytics

Returns the stored URL details and aggregate click analytics for the supplied short code.

### Successful response

Status: `200 OK`

Example response:

```json
{
  "shortCode": "generated-code",
  "originalUrl": "https://example.com/products/123",
  "clickCount": 1,
  "createdAtUtc": "2026-10-21T15:47:52.820461+00:00",
  "lastAccessedAtUtc": "2026-10-21T15:47:52.832438+00:00"
}
```

The values are illustrative. `lastAccessedAtUtc` may be `null` if the URL has not been accessed.

### Error response

- `404 Not Found`: The short code does not exist.

## 4. GET /health

Checks whether the application is responding.

### Successful response

Status: `200 OK`

```json
{
  "status": "healthy"
}
```

This endpoint checks application responsiveness; it does not independently verify database readiness.

## 5. POST /api/requirements/analyze

Analyzes a software requirement and returns a structured engineering plan.

### Request

Content-Type: `application/json`

```json
{
  "requirement": "Build a scalable URL shortener service with APIs, persistence, and analytics.",
  "scenario_type": "greenfield"
}
```

The `scenario_type` field is optional. Supported values are:

- `greenfield`
- `brownfield`
- `ambiguous`

### Response

The response includes:

- The original requirement and scenario type.
- The interpreted engineering problem.
- Assumptions and ambiguities.
- Ordered implementation tasks and dependencies.
- Validation checks.
- Engineering risks and mitigations.
- Examples of AI assistance at different development stages.

The current analyzer uses deterministic rules; it does not invoke a live LLM.

## 6. Data Model

The SQLite `urls` table contains the following fields:

| Field | Description |
|---|---|
| `id` | Internal row identifier |
| `short_code` | Unique short code |
| `original_url` | Original destination URL |
| `created_at_utc` | Creation timestamp |
| `click_count` | Aggregate click count, defaulting to zero |
| `last_accessed_at_utc` | Most recent recorded access timestamp; nullable |

The database enforces uniqueness on `short_code` and requires the short code, original URL, creation timestamp, and click count to be non-null.

## 7. Error Behavior Summary

| Condition | HTTP status |
|---|---:|
| Request validation failure | `422` |
| Unknown short code for redirect | `404` |
| Unknown short code for analytics | `404` |
| Short-code allocation retries exhausted | `503` |

The API's OpenAPI specification is available at `/openapi.json`, and the interactive Swagger UI is available at `/docs` when the application is running locally.
